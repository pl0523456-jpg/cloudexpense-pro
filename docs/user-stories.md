# User Stories

## Employee

- As an employee, I want to register an account so I can submit expenses.
- As an employee, I want to upload receipts so my expenses can be verified.
- As an employee, I want to view my expense history.

## Manager

- As a manager, I want to approve or reject expenses.
- As a manager, I want to add comments to approval decisions.

## Finance

- As a finance user, I want to generate reports.
- As a finance user, I want to export approved expenses.

## Administrator

- As an administrator, I want to manage users.
- As an administrator, I want to monitor application activity.
